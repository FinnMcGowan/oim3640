# Instructions: Build a Python program that analyzes text. Read from files, process strings, and use dictionaries to discover patterns in text data you find interesting.

# Proposal:

## What I'm building:
A Python program that analyzes a text file and finds the most common two-word phrases and repeated word patterns.

## Why I chose this:
I chose this project because I think it would be interesting to see which word combinations appear most often in a book and what that reveals about the writing. Instead of only counting single words, I want to look at short phrases to find patterns that are less obvious.

## Core features:
- Read text from a file
- Clean the text by making everything lowercase and removing punctuation
- Split the text into words
- Build two-word word pairs from neighboring words
- Use a dictionary to count how often each word pair appears
- Display the most common repeated phrases in the text

## What I don't know yet:
- How to clean the text without accidentally removing useful words
- How to handle apostrophes or contractions
- How to skip very common word pairs that are not interesting
- How to organize the dictionary so the results are easy to sort and print
