 - Data Structure:'set'
   - holds unique items only, unordered
     - if a dictioary has some repeated values, set will return only unique values
       - >>> stocks = ['AAPL', 'NVDA', 'AAPL', 'GOOG']
       - >>> unique_stocks = set(stocks)
       - >>> unique_stocks
       - {'GOOG', 'AAPL', 'NVDA'}

   - Sets are faster to run. 
     - finding a value in a list takes much longer than in a set.
